# Screenshots

Images used by the top-level `README.md`. Put new ones here.

The current set was rendered from the game's own objects in small test
scenes (a machine body, the stock station, a vise on a table), not captured
during play:

- `statue_*.png` — the result of `nc_files/trunnion5_ozgurluk_heykeli.ngc`
  run through the game's kinematics and voxel stock.
- `machine_*.png` — machine generator presets.
- `stock_station*.png`, `tool_bench.png`, `vise_setup.png` — hands-on setup.
- `console_*.png` — the control pendant on a live machine, its POS and
  GRAPH pages, and the keypad in the close-up view.
- `chuck_cabinet.png`, `chuck_enclosure.png` — the chuck cabinet: curved
  enclosure (a door slid open), a drawer of jaws out, the stand on the
  worktop.
- `chuck_stand_jaws.png` — a chuck on the stand, key in: one jaw caught by
  the scroll, one lying in its guides, one on the bench.
- `lathe_chuck_on_nose.png` — the slotted chuck on the bench lathe gripping
  a bar, key in.
- `work_order_drawing.png` — a work order's drawing as the HUD draws it.

Still missing, worth adding from a real play session: the workshop seen in
first person, the pendant next to a running machine, the setup
sheet on the HUD, chips during a cut, the generator dock in the editor.

To capture from the game: Godot's embedded game view has a screenshot button,
or use Win+Shift+S. Save as PNG here with a descriptive lowercase name and
link it from `README.md`. This folder has a `.gdignore`, so Godot does not
import these files.
